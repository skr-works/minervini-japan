# 株式スクリーニングシート README

## 概要
このシートは、日本株を対象に、**新高値ブレイク寄りのテクニカル条件**で一次スクリーニングするためのものです。  
A〜C列は基本情報、D列以降はスクリプトによる判定結果です。

## 項目説明

| 項目名 | 解説 |
|---|---|
| 銘柄コード | 証券コードです。シートの基準となる入力項目です。 |
| 銘柄名 | 銘柄の名称です。 |
| 業種 | その銘柄の業種です。 |
| 判定結果 | 総合評価です。`合格` は条件を強く満たす銘柄、`監視` は候補、`除外` は条件外を意味します。 |
| 現在値 | 直近営業日の終値です。 |
| ピボット価格 | 買い判断の目安となる価格です。直近の上値の基準として見ます。売る価格ではありません。 |
| トレンド(50MA) | 50日移動平均線ベースで見た短中期トレンドの状態です。 |
| トレンド(200MA) | 200日移動平均線ベースで見た長期トレンドの状態です。 |
| RS比(52週) | 市場全体と比べて、その銘柄がどれだけ強いかを見る指標です。高いほど相対的に強いです。 |
| VCP示唆 | 値動きが収縮している兆しがあるかを見る項目です。ブレイク前の落ち着いた値動きの参考に使います。 |
| 出来高倍率 | 当日の出来高が、普段の出来高に対してどの程度多いかを示します。大きいほど注目度が高いと見ます。 |
| ボラ高 | 値動きの荒さが最近高まっているかどうかを示します。出来高ではなく、価格変動の大きさです。 |

## 判定結果の見方

| 判定 | 意味 |
|---|---|
| 合格 | トレンド・高値圏・相対的な強さ・ブレイク・出来高の条件をおおむね満たす銘柄です。 |
| 監視 | 強さはあるが、まだ決定的な買い場とは言い切れない銘柄です。 |
| 除外 | 現時点では条件に合わない銘柄です。 |

## シート運用ルール
- 1行目は見出し行です。スクリプトでは更新しません。
- データは2行目から出力されます。
- A列は銘柄コード、B列は銘柄名、C列は業種です。
- 設定によっては、B列とC列をスクリプトで更新します。

## 注意点
このシートは**テクニカル面の一次スクリーニング**用です。  
業績や財務の良し悪しを最終判断するものではありません。  
ファンダメンタルの確認は別のシートや別の判定で行う前提です。
